# Aplicación Clima-App
Aplicación para mostrar el tiempo de diferentes ciudades

# Tecnologias
- Angular 21.2.24
- Node 24.19.0

# Reglas de estilo
- Usa nombres de variables en ingles.
- UI en español
- Usa angular moderno siempre (signals, etc...)
- Usa Tailwind para el css

# Otros
- Es un proyecto educativo. Explicalo todo antes de implementar.
- Incluye comentarios siempre.
- Antes de incluir cualquier codigo en el proyecto, explicamelo
